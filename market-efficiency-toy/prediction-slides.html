Market Efficiency Toy

Prediction Agent and Swarm Performance

Reproducible graphs comparing pretrained, online RL, pre+post-trained, transformer-lite, evolutionary, and weighted swarm predictors across simulated efficient and inefficient markets, including an adaptive crowding cycle where alpha can disappear and re-emerge.

Use the arrow keys, controls, or dots to move through the deck.

How The Experiments Work

Agents predict future excess return from past simulated windows.

Market generator

Returns are generated as drift plus noise plus an expressed latent alpha term: r[t] = drift + (1 - lambda) * alpha[t] + noise[t]. Efficient markets set alpha to zero. Inefficient regimes vary whether alpha is stable, local, rapidly shifting, crowded, or hidden from agents.

Prediction task

Each episode gives the predictor a past window of returns, price trend, volatility, valuation gap, and delayed-news features. The target is up, down, or flat for future excess return over the selected horizon.

Training regimes

Pretrained agents fit historical data and freeze. Online RL agents update after each revealed future. Hybrid agents start pretrained and adapt online. Transformer-lite uses attention over similar historical windows. Evolutionary agents select policy weights on validation data. The swarm votes using recent predictor skill.

Scoring

Directional predictions become confidence-sized positions. Metrics include net PnL, accuracy, Sharpe, calibration error, oracle gap, up/down skill balance, and seed-level stability after transaction-cost and horizon-friction penalties.

How The Markets Were Simulated

Efficiency is controlled by how much latent alpha leaks into future returns.

Return equation

Each simulated period uses r[t] = drift + (1 - lambda) * alpha[t] + noise[t]. When lambda = 1, the predictable alpha term is removed and returns are effectively noise plus drift. As lambda falls, more exploitable structure appears in prices.

Latent alpha

Learnable alpha is generated as alpha[t] = theta[t] dot x[t]. The observable state x[t] contains momentum, valuation gap, and delayed-news features. The coefficient vector theta[t] determines which signal works at that moment.

Efficient null

The efficient regime sets alpha[t] = 0. No public past-window information should predict future excess return after costs. If agents profit here, the pipeline is probably harvesting finite-sample luck, drift, or validation artifacts.

Unlearnable alpha

This regime contains a hidden alpha process, but agents do not observe the hidden state before predicting. It is inefficient from an omniscient perspective, but effectively efficient relative to the agents' information set.

Historical alpha

theta[t] is stable across historical training and future test periods. This favors pretrained and evolutionary agents because old simulated data remains relevant.

Local alpha

theta[t] drifts slowly. Recent interaction predicts near-future alpha better than stale history, so online RL, hybrid, and swarm approaches can adapt.

Rapid shift

The working signal changes quickly. This tests whether learning speed exceeds alpha decay speed. When T_learn > T_decay, both pretraining and online adaptation should struggle.

Crowded alpha

Historical signals decay or partially invert during the test window. This models crowded trades, alpha decay, and regime adaptation after a common edge becomes widely exploited.

What Counts As Alpha?

Alpha is only tradable if it is both present and learnable from the agent's information.

Latent alpha

The simulator can contain a true predictable component in returns. That is the omniscient notion of alpha: a pattern exists somewhere in the data-generating process.

Tradable alpha

Agents only get past-window observations. A hidden signal may exist, but if it is outside the agent's information set, the market is effectively efficient for that agent.

Historical relevance

Pretraining helps when future alpha resembles historical alpha. It hurts when the market changes, crowding reverses the edge, or old examples become stale.

Adaptation speed

Online and swarm methods only help when T_learn < T_decay: the agent must infer the current edge before the edge disappears.

How To Read The Graphs

The deck is about which training regime captures which type of market structure.

Red reference lines

PnL and alpha charts use a red 0% line. Accuracy charts use a red 50% line. Crossing below those lines usually means the model is not extracting useful structure.

Cumulative curves

Cumulative PnL curves show how each agent performs as prediction episodes unfold through the simulated test market. The x-axis is forecast opportunities, not seed number.

Aggregate bars

Regime-level bar charts average across seeds. They answer: in this kind of market, which information-access and training regime wins on average?

Oracle gap

The oracle knows the future label and is not tradable. Its gap measures how much of the theoretical opportunity normal agents fail to capture.
